# Hi 👋, I'm Jorge Rodriguez

### Frontend Developer | React · Next.js · TypeScript

I’m a Frontend Developer focused on building reliable, maintainable and scalable web applications.

My main experience is with **React, Next.js and TypeScript**, working on frontend architecture, API integrations, performance, responsive interfaces and user experience. I have also worked with **React Native** and mobile applications.

I have experience across different types of products and industries, including e-commerce, real estate, education and digital platforms, working both within development teams and on freelance projects.

I value clear code, practical solutions and good collaboration. I’m particularly interested in product-oriented teams where frontend development is closely connected to real user and business needs.
